# 3D Particle Wave Sphere

3D Particle Wave Sphere is a code-based visual simulation created with HTML, CSS, and JavaScript.

This project is not a standard web application or dashboard. It is a fullscreen visual animation project designed to demonstrate creative coding, 3D-style motion, particle animation, and interactive frontend effects.

---

## Project Purpose

The purpose of this project is to create an interactive 3D-style particle sphere using only frontend technologies.

The simulation includes a neon particle sphere, wave deformation, depth projection, mouse-reactive rotation, and particle connection effects. It is suitable for GitHub portfolio, LinkedIn project sharing, YouTube Shorts, and Instagram/Reels content.

---

## Main Features

- Fullscreen visual simulation
- 3D particle sphere
- Neon turquoise glow effect
- Wave deformation animation
- Depth projection effect
- Mouse-reactive rotation
- Particle connection lines
- Smooth animation loop
- Dark futuristic background
- Pure HTML, CSS, and JavaScript

---

## Technologies Used

- HTML
- CSS
- JavaScript
- Canvas API
- Custom 3D projection logic
- `requestAnimationFrame` animation loop
