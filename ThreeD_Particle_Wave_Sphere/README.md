# 3D Particle Wave Sphere

3D Particle Wave Sphere is a code-based visual simulation created with HTML, CSS and JavaScript.

It creates a futuristic particle sphere with wave deformation, neon glow, depth effect and mouse-reactive motion.

## Project Purpose

The purpose of this project is to create a visually impressive 3D-style particle simulation using only frontend technologies.

This is not a dashboard or standard web application.  
It is a fullscreen visual simulation for portfolio, GitHub, LinkedIn, YouTube Shorts or Instagram content.

## Main Features

- Fullscreen particle sphere
- Neon turquoise glow
- 3D depth projection
- Wave deformation effect
- Mouse-reactive rotation
- Smooth motion trail background
- Particle connection lines
- Pure HTML, CSS and JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript
- Canvas API
- Custom 3D projection math
- Animation loop with requestAnimationFrame

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Double-click `index.html`.
4. The simulation starts automatically.
